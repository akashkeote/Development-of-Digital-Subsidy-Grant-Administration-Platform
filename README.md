# Gov Subsidy Demo

This repository contains only a scheme demo.

## Clone the Repository

```bash
git clone https://github.com/akashkeote/Government-Subsidy-Grant-Disbursement-Tracking-System.git
cd Government-Subsidy-Grant-Disbursement-Tracking-System
```

## Step to Run Current Backend

1. Open a terminal in the repository.
2. Go to the `backend` folder.
3. Run:
   ```bash
   # Windows
   .\gradlew.bat bootRun

   # macOS / Linux
   ./gradlew bootRun
   ```

The backend runs on `http://localhost:8080`.

## Step to Open Existing Demo Frontend

1. Go to the `frontend` folder.
2. Run:
   ```bash
   flutter pub get
   flutter run
   ```

If Flutter is not installed, skip the frontend step for now. The frontend is temporary and will be moved to React later.
